# Custom Google Search UI 🌌

A sleek, custom Google Search homepage implementation featuring a dark galaxy visual theme, semantic HTML structure, and a clean user experience.

---

## ✨ Features

- **Semantic HTML5 Layout:** Structured with accessibility standards using native forms, ARIA landmarks, and hidden labels.
- **Custom Visual Theme:** Galaxy background layer coupled with a centered search panel.
- **Form Controls:** Clean search input with disabled browser autocomplete and automatic focus upon loading.
- **Privacy Focus:** Built-in notice section linking directly to privacy details.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic architecture, accessible forms, and structured metadata.
- **CSS3:** Custom styles, responsive layout, and background layering (`style.css`).
